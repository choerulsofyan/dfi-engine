# DFI API (Legacy)

This repository contains the API developed in 2019 for the [DFI website](https://dfi.id/) as part of a freelance project. The API was designed to support the digital forensic services and online presence of Digital Forensic Indonesia at that time.

> **Note:** This codebase is legacy and is no longer actively maintained or used by the current DFI website team. It is provided here for historical reference and as a potential starting point for future development.

## Project Overview

- **Project Name:** DFI API
- **Project Year:** 2019
- **Purpose:** Developed to handle data operations for digital forensic services.
- **Status:** Legacy (Not in active use)
- **Development Context:** Freelance project

## Technology Stack

- **Backend Framework:** Laravel 5.8
- **PHP Version:** ^7.1.3
- **API Authentication:** Laravel Passport (^7.5)
- **CORS Handling:** Barryvdh/laravel-cors (^0.11.4)
- **CLI Tool:** Laravel Tinker (^1.0)
